# Demo

You can spin up the same demo I used to confirm that the highlighting is working.

![Screenshot of demo environment](demo.png)

## Setup

Run `npm install` in the compiler and highlighter folders.

In the demo folder, run `node server.js`

Use a basic HTTP server (I recommend the "Open in Default Browser" VSCode extension) to open index.html.

Hold shift to preview before and after. Try shift + right and shift + down to quickly cycle through the themes and grammars.
